## 🚀 Getting Started

1. **Add Repository**: In SkyStream, navigate to **Settings** > **Manage Extensions** and add this short code:
   ```
   MightySolarRayNSFW
   ```
   **OR**
   ```text
   https://raw.githubusercontent.com/MightySolarRay/sky-rated/main/repo.json
   ```
3. **Download Plugins**: Install your desired extensions from the list.
4. **Switch Provider**: On the **Home Screen**, tap the provider switcher icon at the bottom right and select any of the `[MSR]` adult providers.
